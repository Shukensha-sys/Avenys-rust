# MORE - Mire Official Records & Evolution
Mire Official Records &amp; Evolution, but you can call it RFCs

Each MORE document is identified using a numeric identifier:

```text
MORE-1  — Updated std module
MORE-2  — Owl package layout
MORE-3  — FFI ABI design
```

### Status

A "MORE" document may have one of the following states:

* Draft
* Reviewing
* Accepted
* Implemented
* Rejected

### Scope

"MORE" documents may cover:

* Language syntax and semantics
* Compiler architecture
* Runtime behavior
* Owl tooling and package management
* Standard library changes
* ABI and FFI specifications
* Formatting and ecosystem conventions
* Performance and optimization designs

### Repository Structure

```text
more/
├── 0001-std-module-update.md
├── 0002-owl-package-layout.md
├── 0003-ffi-abi.md
```

MORE exists to provide LTS, transparency, and technical direction for the entire Mire ecosystem.
